# Implementation evidence trail — PPkt (network layer)

The engine and test files cite `task-N-report.md` as the justification of record for
several decisions. Those reports were written into a gitignored scratch workspace
during implementation; they are copied here so the citations point at something a
reader actually has.

- `00-decision-ledger.md` — every ruling made while executing the plan, in order,
  each with what it costs if wrong. This is the honest record of the judgment calls,
  including two rulings that later turned out to be wrong and were corrected.
- `task-N-report.md` — the implementer's account of task N, plus any fix rounds
  appended after review.
